## 素材来源

- **官方原生 SVG**（17 款）来自厂商网页或素材 CDN。部分文件清除了源文件中的隐藏图层，或将白色版改为黑色。路径轮廓保留。
- **官方 PDF 矢量**（45 款）提取自厂商目录中的独立型号标志，保留矢量轮廓。部分浅色路径改为黑色，便于放在浅色边框上。PDF 页码按文件从第 1 页计起。
- **官方位图描边**（12 款）根据佳能官网的透明 PNG 轮廓生成路径。放大时按矢量绘制，轮廓精度取决于源图分辨率。 [佳能 EOS R 系统页](https://www.usa.canon.com/digital-cameras/eos-r-system)

还有 34 款暂未收录，包括 Canon EOS R6 Mark III、EOS R8 Mark II、Nikon D6，以及 Leica、Hasselblad、Sigma 本次核对的机型。目录保留这些型号和厂商链接，便于查找后续公布的素材。[逐机型目录与来源](catalog.csv)

## 在光印中使用

下载机型 SVG。在照片编辑页依次选择「图层」「添加图层」「自定义 Logo」，选中下载的 SVG。可与 EXIF 参数图层一起保存到预设。

以 Nikon ZR 为例，文件保留了官方封面的双线 Z 与 R 字形，背景透明。 [ZR SVG](nikon/zr.svg) · [尼康官方目录](https://nij.nikon.com/cms/products/lineup/z_cinema/zr/pdf/zr.pdf#page=1)

各型号标志用于标注照片拍摄设备，相关权利归各自持有人。KaiPrint 的 MIT 许可证适用于项目自有代码。
